Media Pruner

Automatically or manually deletes movies (Radarr) and series (Sonarr) based on your criteria.

Radarr (movies)
Radarr → Settings → General → Security.
Sonarr (series)
Sonarr → Settings → General → Security.
Deletion criteria
Items with any of these tags in Radarr/Sonarr are never deleted automatically.
Deletion mode
When disabled, deletion is manual only, from the "Pending deletion" tab. The schedule is set in Dashboard → Scheduled Tasks → Media Pruner.
The automatic task logs what it would delete without deleting anything. Recommended to validate your criteria.
Jellyfin tag
Adds a Jellyfin tag to movies and series that will be deleted within the "Show items deleted within the next X days" window (excluded items are not tagged). The tag is removed automatically once an item is protected, favorited, etc. Updated by the scheduled task and when the "Pending deletion" tab is opened.
Users can filter the library by this tag to see what will disappear soon.
Jellyfin collection
Keeps a Jellyfin collection with the same items as the tag: items are added and removed automatically. Unchecking this deletes the collection created by the plugin (the media themselves are not affected).
Renaming here renames the existing collection.
